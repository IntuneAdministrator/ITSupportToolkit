# Install & Deployments

All local launchers and enterprise deploy packages live here. Keep this folder next to `Windows/`, `macOS/`, and the toolkit binaries in the toolkit root.

| Folder | Platform | Channel |
|--------|----------|---------|
| [Run Locally Windows](Run%20Locally%20Windows/) | Windows | Manual / USB |
| [Run Locally macOS](Run%20Locally%20macOS/) | macOS | Manual / USB |
| [Run On Active Directory Windows](Run%20On%20Active%20Directory%20Windows/) | Windows | GPO / SMB |
| [Run On Active Directory macOS](Run%20On%20Active%20Directory%20macOS/) | macOS | SMB / ARD / launchd |
| [Run On Cloud Intune Windows](Run%20On%20Cloud%20Intune%20Windows/) | Windows | Intune Win32 |
| [Run On Cloud Intune macOS](Run%20On%20Cloud%20Intune%20macOS/) | macOS | Intune PKG |
| [Run On Cloud Jamf macOS](Run%20On%20Cloud%20Jamf%20macOS/) | macOS | Jamf Pro PKG |

Open each subfolder’s `README.md` for exact commands and console steps.
