# Run Locally Windows

Start the toolkit on a Windows PC without Intune/AD.

## How to run

1. Keep **`Install & Deployments`** inside the toolkit root (next to `Windows\`, `macOS\`, and `IT Repair & Diagnostic Toolkit.exe`).
2. Double-click **`IT Repair & Diagnostic Toolkit.lnk`** (preferred — custom icon)  
   — or **`Start Toolkit.bat`** as a plain fallback.

## Notes

- Cloud deploy: `Install & Deployments\Run On Cloud Intune Windows\`
- Domain GPO: `Install & Deployments\Run On Active Directory Windows\`
